# AI自动阅卷系统 — 分阶段开发路线图

> 版本：V1.0  
> 目标：基于PRD V1.3实现完整MVP闭环  
> 总阶段数：8 个阶段（建议按顺序迭代，每阶段可独立验证）

---

## 阶段 0：项目基础脚手架与认证（预计 1 个迭代）

**目标**：搭建前后端项目骨架、数据库、Docker 环境、RBAC 认证体系。

### 后端任务
- [ ] 初始化 FastAPI 项目结构、依赖配置（requirements.txt）
- [ ] 配置 PostgreSQL + Redis + Celery 连接
- [ ] 创建 Alembic 迁移脚本
- [ ] 实现 `users`、`role_permissions` 模型与初始化数据
- [ ] JWT 登录、登出、Token 刷新
- [ ] 全局异常处理、审计日志中间件
- [ ] RBAC 权限装饰器（四种角色权限校验）

### 前端任务
- [ ] 初始化 Vue 3 + Vite + TypeScript 项目
- [ ] 引入 Element Plus、Pinia、Vue Router、Axios
- [ ] 登录页面、全局路由守卫、403/404页面
- [ ] 按角色动态菜单渲染
- [ ] Axios 封装、Token 自动刷新、全局错误提示

### 交付物
- 可登录系统，区分四种角色菜单
- 用户管理 CRUD（仅超级管理员）
- Docker Compose 一键启动开发环境

## 迭代优先级建议

| 优先级 | 阶段 | 说明 |
|--------|------|------|
| P0 | 0、1、2 | 基础认证、考试管理、答题卡模板是后续所有模块的前置条件 |
| P1 | 3、4、5 | 导入切割、OMR、人工/AI 阅卷是系统核心价值 |
| P2 | 6、7 | 预阅卷、学情分析提升可用性与教研价值 |
| P3 | 8 | 导出归档、系统设置、审计日志完善闭环 |
